About Acme Guides

Acme Guides is a small, independent collection of how-to guides for the tech chores people keep putting off.

We started it because most help articles bury the useful part under ads, upsells and long introductions. Each guide here does the opposite. It says what you will end up with, lists the steps in order, and stops. If a step only applies to some people, we say so instead of hiding it in a footnote.

Every guide is tested on real machines before it goes up, and we revisit them when the tools they describe change. When we get something wrong, we fix it and keep the date of the change on the page.

How the site is funded

There are no ads, sponsored links or paid placements. The site is cheap to run because it is plain HTML with a small API, and we cover the hosting ourselves.

For developers and agents

The same guides are available as a read-only JSON API, an MCP server for AI agents, and plain Markdown. Use them in your own tools. A link back is appreciated but not required.

Questions, corrections or ideas for a new guide are always welcome on the contact page.
