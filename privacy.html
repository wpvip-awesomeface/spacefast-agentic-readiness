Privacy

Last updated October 9, 2026

Short version: this site has no analytics, no ads and no tracking cookies, and it never asks you for personal information.

What gets collected

When you load a page, our hosting provider receives the details every web server sees: your IP address, your browser's user agent, the page you asked for and the time. Those logs are kept for a short period to keep the site running, block abuse and fix problems. We don't use them to build profiles, and we don't sell or share them.

There are no accounts, newsletters or comment forms. The only personal information we ever hold is what you choose to send us by email, which we keep so we can reply.

Agent and API access

The API, the MCP server and the anonymous agent sign-up don't require an account and don't store anything about the caller. The optional OAuth flow keeps a one-time authorization code for up to five minutes so the token exchange can finish. Anonymous agent keys are generated on request and never saved.

Your choices

You can block cookies in your browser and the site will still work. If you have a question about your data, or want an email you sent deleted, write to hello@acme-guides.example. If this policy changes, the date at the top of the page changes with it.
